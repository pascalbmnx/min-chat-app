Build a **full-stack modern Chat Web Application** with a professional, scalable architecture and a premium user experience.

## Core Features

### 1. Authentication

* Register
* Login
* Logout
* Secure password protection
* Session-based authentication
* Forgot password
* Password reset

### 2. User Profiles

* Profile photo
* Full name
* Username
* Bio
* Online/offline status
* Last seen
* Edit profile
* View other users' profiles

### 3. Private Chat

* One-to-one conversations
* Send and receive messages
* Message timestamps
* Read/unread status
* Typing indicator
* Delete messages
* Search conversations

### 4. Group Chat

* Create groups
* Group name, photo and description
* Add/remove members
* Group administrator controls
* Group messaging
* Leave group
* View group members

### 5. Chat Features

* Text messages
* Image and file sharing
* Message notifications
* Unread message counters
* Emoji support
* Automatic message updates
* Responsive mobile and desktop experience

## UI/UX

Create a **premium, modern messaging interface** inspired by contemporary communication applications.

Include:

* Clean dashboard layout
* Conversation sidebar
* Beautiful chat window
* Profile information panel
* Modern message bubbles
* Responsive design
* Dark/Light mode
* Smooth transitions and micro-animations
* Skeleton/loading states
* Toast notifications
* Useful empty states
* Attractive cards and buttons
* Professional SVG icons
* Mobile-friendly navigation
* Excellent spacing and typography
* Strong visual hierarchy
* Minimal and elegant visual effects
* Avoid excessive gradients and unnecessary animations

## Backend & Security

Implement a secure and scalable backend architecture.

Include:

* Authentication and authorization
* Secure password handling
* Input validation
* Protection against SQL injection
* XSS protection
* CSRF protection
* Secure session management
* File upload validation
* Access control
* Proper API error handling
* Secure handling of user-generated content
* Proper validation of all requests

## Database

Design a normalized relational database supporting:

* Users
* Profiles
* Conversations
* Conversation members
* Messages
* Groups
* Group members
* Message read status
* Notifications
* Attachments
* User sessions/status
* Other supporting relationships required by the application

Ensure proper relationships, indexes, constraints and data integrity.

## Architecture

Organize the application professionally with clear separation between:

* User interface
* Authentication
* Application logic
* API layer
* Database layer
* File management
* Reusable components
* Configuration
* Assets
* Uploaded files

Create reusable modules and maintainable code throughout the application.

## Important

Build a **fully functional production-ready application**, not a prototype.

Do not include:

* Placeholder functionality
* Fake data
* Demo-only features
* "Coming Soon" sections
* Lorem ipsum
* Non-functional buttons
* Broken forms
* Simulated chat functionality

All major buttons, forms, authentication features, messaging functionality, group management, notifications, profile management, file sharing and database operations must be **fully functional and connected to the backend**.

The final application should feel like a **real modern messaging platform**, with a clean interface, smooth interactions, reliable functionality and a structure that can be extended in the future.
